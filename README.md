# Ghostlike Apparition

Röhren-Amp-Plugin (AU/VST3, macOS) der Augsburger Metalcore-Band Ghostlike.

- **Installieren:** neuesten Installer unter [Releases](https://github.com/timetellervideography/ghostlike-apparition/releases/latest) laden und doppelklicken. Meldet macOS „nicht geöffnet“: *Fertig* klicken, dann *Systemeinstellungen → Datenschutz & Sicherheit* ganz unten *Dennoch öffnen*. (Der Installer ist noch nicht von Apple notarisiert.)
- **Updates:** im Plugin *Einstellungen → Nach Updates suchen*. Sounds, Amps, Presets und Optik kommen so ohne Neuinstallation.

`src/` ist die Web-Vorschau und Quelle aller Werte und der Oberfläche, `plugin/` das JUCE-Plugin (siehe [plugin/README.md](plugin/README.md)).
Das Plugin nutzt [JUCE](https://juce.com) unter AGPLv3.
